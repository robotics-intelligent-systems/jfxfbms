# AI-Powered Airlines Management Platform

PrepPilot — AI Placement Preparation Platform. The goal of the D-Jet open4aviation project is to construct a small jet for an emerging market. The Travel Market Simulator project aims at providing reference implementation, mainly in C++, of a travel market simulator, focusing on revenue management (RM) for airlines. Virtual Airlines Manager (VAM) is a free airlines manager system. HAL Koraput Inventory Management System (IMS) is a Flask-based web application to manage inventory items, suppliers, purchase orders, consumption logs, and user accounts. AirOpsManager is a full-stack airline operations platform. Aviation Management System is a comprehensive web application for managing aviation operations, maintenance, and aircraft data. Aircraft Maintenance System simulates real-time aircraft engine monitoring, diagnostics, and auto-fixing. AeroCare is a predictive maintenance solution. LibreBooking is an open-source resource scheduling solution. Property Management Solution Powered on ERPNext. ABAP Flight Reference Scenario for the ABAP RESTful Application Programming Model. Implementation of the Saga pattern for the classic trip booking example using the lightweight open source workflow engine (Camunda). Airline crew scheduling system using Google OR-Tools CP-SAT solver. Mercury is a research-oriented air transportation mobility simulator. Java library for the Amadeus Self-Service travel APIs. Sabre Java Bridge. The Airplane Ticket Booking and Management System is a modern web application designed to streamline the process of booking and managing flight tickets. phpVMS is a PHP based application to run and simulate and airline. AeroACARS is a modern, cross-platform ACARS client for phpVMS 7. PyQt6-based ACARS (Aircraft Communications Addressing and Reporting System) application for MFS. Airplane Hangar Management System, a web application that allows users to manage hangars, aircraft, reservations, and generate reports.

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
